# Factors deferred after Phase B3

| Candidate | Minimum missing evidence | Current status |
| --- | --- | --- |
| Analyst Estimate Revision / Consensus Earnings / Expectation Gap | Dated analyst estimates, forecast publication and revisions with licensed historical access | UNAVAILABLE |
| True Earnings Surprise | Point-in-time consensus before actual results, exact result publication time and comparable accounting basis | UNAVAILABLE |
| Management Quality / Competitive Moat | Explicit, testable source observations and validated measurement rules | UNAVAILABLE |
| Industry Cycle | Historical, point-in-time industry classification and sector operating data | UNAVAILABLE |
| Catalyst Score | Dated, categorized, qualified official event records | UNAVAILABLE |
| Ownership Change / Announcement Event | Qualified official documents with IDs, true publication time, document references and licensed API access | UNAVAILABLE |

A low valuation percentile plus drawdown might someday become a **proxy for low expectation**, but it would require `FactorType.PROXY` and explicit limitations. It is not a market-expectation observation and is not implemented in this round.
